# Window

## Requirements

| ID | Requirement | Status | Verified by |
|----|-------------|--------|-------------|
| `WIN-1` | Starting cmx with no files opens one window at the size from `[window] width` and `height` (`CONF-4`). The window restores the last comic (`READ-41`) or shows the placeholder (`WIN-5`). Starting cmx with files opens one window for each file. | done | `scripts/manual/open.sh` |
| `WIN-2` | The app is single-instance. Starting it again while it runs opens the new windows in the running process: one for each file given, or one empty window when no file is given. `new-window` opens an empty window. | done | `scripts/manual/open.sh`, `scripts/manual/smoke.sh` |
| `WIN-3` | Every window has the Wayland app ID `io.github.DisposableSoftware.cmx`, so compositor window rules match it. | done | `scripts/manual/smoke.sh` (headless: `swaymsg` reports the app ID) |
| `WIN-4` | `close-window` closes the focused window. Closing the last window quits the app. `quit` closes every window. | done | `scripts/manual/smoke.sh` |
| `WIN-5` | A window with no comic shows two lines centred on black. The first line is "Open a comic". The second line, smaller and dimmer, is "KEY, or drop a .cbz here", where KEY is the label of the first `open` key. When `open` has no keys, the second line is "Drop a .cbz here". While a comic opens, the window shows a spinner instead. | done | `scripts/manual/smoke.sh` (screenshot) |
| `WIN-6` | The page view has a black background, and nothing is drawn over the pages. Pages are scaled up or down to fit the window, keeping their aspect, and centred. Two pages are scaled to the same height and meet at the centre line between them, and the pair is fitted to the window as one image. Pages are drawn smoothly filtered at the display's full resolution (`LOOK-1`). | done | `layout::tests`, `scripts/manual/paging.sh` (screenshots) |
| `WIN-7` | The window title is the comic's display title (`READ-14`), then ` · ` and the page indicator: `3 / 42`, or `3–4 / 42` when two pages are shown. A window with no comic is titled `cmx`. | done | `reader::tests`, `scripts/manual/paging.sh` |
| `WIN-8` | `open` shows the GTK file dialog, filtered to comics (MIME type `application/vnd.comicbook+zip`, or the pattern `*.cbz` in any case). Several files can be selected. Files can also be dropped onto a window, and dropped files without a `.cbz` extension (any case) are ignored. The first comic opens in the window it came from when that window has no comic and isn't opening one. Every other comic opens in a new window. Files from the command line or a file manager always open new windows. | done | `scripts/manual/open.sh` |
| `WIN-9` | When a comic that is already open in a window is opened again, that window is brought forward, and no second window opens. Paths are compared after resolving symlinks. | done | `scripts/manual/open.sh` |
| `WIN-10` | An error (`READ-1`, `READ-3`…`READ-5`) is shown in a modal dialog on its window, with the message and an OK button. A window whose comic failed to open stays open and shows the placeholder. | done | `scripts/manual/open.sh` (screenshot of the RAR error) |
| `WIN-11` | Best effort: when a comic opens, a floating window resizes once to the aspect ratio of the first page shown. The height stays the same, except that a window still at its starting size takes 85% of the monitor's height. The size is then shrunk to fit inside 95% of the monitor, title bar included, and grown to at least 400×500 logical px. Both steps keep the aspect, and the result is rounded to whole px. Page turns never resize the window. Maximized, fullscreen and tiled windows are left alone. On Hyprland, which tiles most windows, this rarely applies, so its behaviour there isn't checked. | done | `fit::tests`, `scripts/manual/open.sh` (headless: floating window aspect matches the page) |
| `WIN-12` | `toggle-fullscreen` enters or leaves fullscreen. `exit-fullscreen` leaves fullscreen, and does nothing when the window isn't fullscreen. | done | `scripts/manual/paging.sh` |
| `WIN-13` | `toggle-info` shows or hides a 260 px panel on the right of that window. The page area shrinks to make room, so the panel never covers the page. The panel lists the metadata fields that exist, as label and value, in this order: Series, Number, Volume, Count, Title, Writer, Penciller, Inker, Colorist, Letterer, Cover Artist, Publisher, Date (`Year-Month-Day` from the parts that exist), Pages, Language, Genre and Web. Summary follows under its own heading. Values wrap and can be selected, and the panel scrolls when it is too long. A comic without metadata shows "No metadata in this file." | done | `scripts/manual/info.sh` (screenshots with and without metadata) |
| `WIN-14` | In a window with no comic, the page actions, `toggle-dual-page` and `toggle-info` are disabled and do nothing. | done | `scripts/manual/smoke.sh` |
| `WIN-15` | `about` opens an About dialog with the name, the version, "cmx is pronounced “see-mix”.", the MIT licence, the homepage, and the third-party crates cmx depends on directly (`zip`, `quick-xml`) with their licences. | done | manual (`scripts/manual/smoke.sh` screenshot) |

## Implementation notes

- On Wayland a window can't place itself, so `WIN-11` only sets the size. The fit rules are a pure function (`fit.rs`), so they can be tested without a window.
- Hyprland tiles new windows, so the resize in `WIN-11` can only be seen on a floating window. Headless sway floats every window.
- Files from the command line arrive in GApplication's `open` handler, which must take `app.hold()` before spawning the async open. A hold taken inside the future is too late: the handler returns with no window and no hold, and the app quits with status 0.
- `toggle-info`'s panel sets `hexpand(false)` on purpose: its value labels expand, and GTK propagates that up, so without it the panel takes a share of the spare width beyond 260 px.
