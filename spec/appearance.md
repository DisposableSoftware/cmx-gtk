## Implementation notes

- At scale 1, GTK's default font rendering leaves 1px strokes in small text faint. If that matters, set `gtk-font-rendering` to manual with hinted metrics only when every monitor has scale 1 (see Junk Drawer's `theme::set_font_rendering`).
- `LOOK-3`: black is the only hard-coded colour. A palette colour would tint comic pages that have a transparent or white margin, and `WIN-6` rules out anything drawn over the pages. In the empty window this means `text` and `overlay1` sit on black, which is low contrast on latte.
- `LOOK-5`: the stock `dim-label` class dims by opacity, so the stylesheet sets its colour and `opacity: 1` inside the panel.
- The error dialog (`WIN-10`) is a `gtk::AlertDialog`, and GTK gives no handle to put a CSS class on it, so it follows the GTK theme, not the flavor.
- The colours are the [Catppuccin](https://catppuccin.com) palette by the Catppuccin community ([github.com/catppuccin/catppuccin](https://github.com/catppuccin/catppuccin)). `data/themes/*.css` are copied verbatim from Junk Drawer and keep their header comment with the palette link. The README credits Catppuccin.
